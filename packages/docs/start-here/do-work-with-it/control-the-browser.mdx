---
title: "Control the browser"
description: "How to use JuggleWork to automate the built-in browser"
---

Computer-use in JuggleWork currently works through the built-in JuggleWork Browser. It does not yet mean full desktop control of Ubuntu, macOS, or Windows apps.

JuggleWork can open pages, click, fill forms, read page content, and take screenshots inside that browser. If you connect to a remote JuggleWork server, the browser runs on that remote worker.

Today, the supported path is the first-party `JuggleWork Browser` extension.

## Requirements

- Use the desktop app or a remote worker that exposes the JuggleWork Browser.
- Keep `JuggleWork Browser` enabled in `Settings > Extensions`.

Then go back to the session view and ask JuggleWork to open a website.
