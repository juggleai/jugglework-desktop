---
title: "Self-host a workspace"
description: "Run a private JuggleWork workspace host and connect the desktop app to it."
---

The desktop repository supports self-hosting an individual workspace through
`openwork-server`. Organization accounts, shared providers, and the hosted
control plane are supplied by the separate JuggleWork server deployment.

## Run the host

The repository includes a Docker template in `packaging/docker` that starts
OpenCode and exposes only the authenticated JuggleWork host API.

```bash
cd packaging/docker
docker compose up --build
```

Configure strong values for:

- `OPENWORK_TOKEN`
- `OPENWORK_HOST_TOKEN`

Persist `/workspace` for project files and `/data` for host and OpenCode state.
Put HTTPS and your normal access controls in front of port `8787` before
exposing it outside a trusted network.

## Connect the desktop app

In JuggleWork, create a remote workspace and provide:

- The public JuggleWork host URL.
- The client token configured as `OPENWORK_TOKEN`.

The desktop app connects to the JuggleWork host API. OpenCode remains private
behind that API and should not be exposed directly.

For organization-level deployment, authentication, provider policies, and the
web dashboard, use the independently maintained `jugglework-server`.
