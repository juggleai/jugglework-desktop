title: "Add a custom LLM"
description: "How to connect a custom provider with JuggleWork"
---

### From the app

Open **Connect providers** (Settings → Providers, or the model picker) and pick **Custom provider**. Fill in a name, the OpenAI-compatible base URL, your API key and the model IDs the endpoint serves — one per line, optionally as `model-id = Display name`. JuggleWork writes the provider block into the global OpenCode config and stores the key in OpenCode's local credential store, so the config file itself carries no secret. The model group is available in every workspace on that runtime. In Settings, locally added groups carry a **Local** badge; select one to edit its endpoint and models. Works with any OpenAI-shaped gateway, relay or self-hosted proxy.

The optional context/output limits enable context tracking and auto-compaction for those models; leave them empty to use the engine defaults.

### By hand

Because `JuggleWork` is built on `OpenCode` primitives, we support everything that you could modify in OpenCode configuration, like adding a [model](https://opencode.ai/docs/models/). To make a provider available to every workspace, add it to the global `~/.config/opencode/opencode.jsonc` file. If `OPENCODE_CONFIG_DIR` is set, use the `opencode.jsonc` file in that directory instead.

Inside the global `opencode.jsonc`:
```
{
  "provider": {
    "my-api": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "My model",
      "options": {
        "baseURL": "https://your API address/v1"
      },
      "models": {
        "model-name": {
          "name": "Model name"
        }
      }
    }
  }
}
```

### Functional example: Ollama (Qwen3 8B)

This setup a local [Ollama](https://docs.ollama.com/api/openai-compatibility) instance running `qwen3:8b`. 

```
{
  "provider": {
    "ollama": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ollama",
      "options": {
        "baseURL": "http://localhost:11434/v1"
      },
      "models": {
        "qwen3:8b": {
          "name": "Qwen3 8B"
        }
      }
    }
  }
}
```

Pull the model first with `ollama pull qwen3:8b`, then make sure the Ollama server is reachable at `http://localhost:11434` with `ollama serve`

Open your desktop, change the provider name and voila! You have an fully local LLM running in your machine.

For teams, you can manage the provider in JuggleWork Cloud under [LLM Providers](/cloud/share-with-your-team/managed-llm-provider), then import it into each workspace from `Settings -> Cloud`.
