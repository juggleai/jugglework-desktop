# jugglerouter-provider — Connect JuggleRouter as a built-in AI provider

Approved demo narration for the JuggleRouter provider connection experience.

1. 打开“设置 → AI Providers → 添加 Provider”。

2. 列表中出现 `JuggleRouter`。

3. 点击后显示官网入口和 API Key 输入框。

4. 输入 Key 并连接。

5. JuggleWork 自动读取 JuggleRouter 模型目录，只导入支持对话的模型。

6. 引擎自动重新加载，Provider 显示为“已连接”。

7. 新建对话，在模型选择器中选择 `JuggleRouter → gpt-5.3-codex`。

8. 发送一条代码任务并成功收到流式响应。

9. 断开 JuggleRouter 后，凭据被删除且模型不可再调用。
