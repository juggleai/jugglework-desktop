## Context

截图显示命中筛选的子任务可以同时作为独立行和展开分支中的行。层级不代表授权或状态聚合。

## Decisions

- 创建时设置同组织且可编辑的父任务，之后不改父级；每次只加载直接子任务，不需要递归写入或读取。
- 现有任务 API 返回可见父任务摘要和可见直接子任务的完成数/总数，以及该任务回复数；附件数从已保存任务描述提取。服务端权限过滤优先，隐藏或删除的父任务不返回标题或 ID。
- 子任务页使用 `view=all&parentTaskId=...`，独立于外层筛选与排序。列表默认展开可见分支。任务视图默认保留匹配筛选的外层子任务。全部任务、我创建的、我分配的和已完成提供显隐菜单，选择隐藏时使用 `excludeSubtasks=true` 从外层结果中排除子任务，父任务仍可展开。列表与详情的子任务分别分页。
- 完成、重开、软删除、恢复和清单归类不级联。创建不继承清单、权限、负责人或完成策略。父任务软删除期间子任务仍可按自身权限访问。
- 详情在任务清单下方展示子任务区和添加按钮。旧服务端缺少子任务计数时，向可编辑任务的用户展示禁用按钮和更新提示，避免误建普通任务。评论计数使用服务端按页返回的总数，发送评论后刷新列表，不逐条请求评论。上线顺序为迁移、Server、Desktop。
- 详情子任务标题区用已完成数/总数和灰底进度条展示进展：部分完成填充蓝色，全部完成填充绿色。子任务列表底部放置圆角行内草稿与添加入口；截止日期复用主任务的日历和具体时间选择，只写入创建草稿，不展示开始日期或提醒设置。
- 草稿与已创建子任务共用紧凑的截止日期显示，具体时间非零时保留时分，铃铛只作截止信息的视觉标记。主键点击编辑行外部与回车走同一提交逻辑；日期与负责人浮层（包括时间菜单）属于草稿，不触发提交。
- 空字段和详情箭头在行悬停或键盘聚焦时出现，已填字段常驻。日期悬停或聚焦可单独清除截止时间。已保存子任务的标题、日期与人员写入以子任务详情权限和版本为准，父任务编辑权限不作为依据。标题失焦提交，详情导航使用独立箭头；子任务头像摘要最多两格。
- 子任务详情和展开清单消费同一个服务端顺序；旧服务端以创建时间升序分页且不展示拖动手柄。父任务可编辑时可凭手柄将某条已加载的子任务移到同级可见项前后；服务端按当前权限重验。失效的子任务游标从第一页重新加载，不把两种顺序拼接。
- 详情子任务行首的排序手柄默认隐藏，悬停整行或键盘聚焦手柄时显示。行首保留固定空间，不因显隐移动完成按钮或标题。
