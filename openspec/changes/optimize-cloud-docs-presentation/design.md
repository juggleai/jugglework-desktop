# 云文档视图稳定性与加载展示

## 目标与边界

左侧纵向导航悬浮不替换云文档画面；隐藏会话不得显示或聚焦原生页。切回已有标签复用同一实例，不新增授权、导航或保存动作。正文不同初始化阶段使用一致的展示，不将命令桥可用误称为正文已完成。

不修改 launch grant、账号／租户 partition、固定 context、ACL、失权处理、协作协议、草稿、保存和关闭屏障。普通文档、表格、幻灯片维持原编辑器生命周期与 render key。

## 原生视图与浮层

- rail 普通提示统一使用系统原生 title，保留 aria-label，不生成跨原生内容的 DOM Tooltip；外观和出现延时由系统管理。导航预览、真实菜单和模态交互仍保留。
- 原生显示要求所属会话 surfaceVisible、选中标签、ready、窗口可见及宿主实际可见且有尺寸同时成立。surfaceVisible 由 SessionRoute 经轻量 context 传至 FilesPanel／CloudDocPanel，不进入 launch/open effect 依赖，不卸载已访问标签。
- 非模态菜单、列表及侧栏预览只有与宿主相交时才遮挡；可见模态始终阻断。原生页显示期间，真实遮挡使用当前实例截图。截图图片就绪后隐藏原生页；失败或无图时，主题占位提交并经过绘制机会后再隐藏，不能留下盖住菜单的原生层，也不能显示空白。
- 浮层消失时先恢复原生视图，等待 IPC 屏障和绘制机会再移除截图／占位。过期截图、onLoad 和异步恢复结果不操作新的激活来源。
- Main 按每个 view 的实际 bounds、圆角和可见性去重；相同尺寸的不同实例仍执行前台归属切换。隐藏页拒绝会聚焦的侧栏／搜索命令，后台 request-state 不聚焦。

## 正文加载

Docs 仓库的受管文档作用域、Office 判型、异步编辑器和正文初始加载共用主题背景、尺寸规则、spinner 和文案。只统一展示，不增加阻塞子组件挂载的父门禁；非受管界面保留原有骨架。正常 dirty 编辑和协作更新不触发初始加载占位。

Office describe 按 context／workspace／doc 共享整个在途 Promise，包括 JSON 读取阶段；每批不超过 100 个。结算立即释放，不缓存已完成的类型或授权结果；context 变化拒绝旧查找，旧响应不能删除或发布新查找结果。失败允许重新请求。

docs.ready 继续表示工作区命令桥可用，未新增正文就绪协议。本次不承诺只有一次组件 mount，也不通过提前报告 ready 隐藏实际加载。

## 验证与限制

回归覆盖普通 rail hover 不触发截图、真实遮挡交接、截图失败、过期回调、后台非零尺寸及 ready/layout 不显示或抢焦点、前台恢复复用、多实例相同 bounds 切换，以及加载阶段推进、dirty 内容保护、在途查询复用和身份切换。

隔离 Electron 命中测试验证真实 WebContentsView 与 DOM 菜单指针交互；完整桌面导航连续悬浮的视觉录屏、真实授权协作及保存端到端验收仍独立进行。Electron 全量类型检查受既存范围外测试错误阻塞，定向检查不等同于全仓通过。
