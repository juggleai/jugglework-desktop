# Tasks

## 1. 会话能力与作用域

- [ ] 1.1 核对原生任务、通讯录、日历、会议与 IM 的可用契约，在 dev 会话中验证工具调用能携带可信的原会话与运行身份；缺少身份或业务契约的入口保持不可用，并记录缺口。
- [ ] 1.2 在 Desktop 全局宿主注册有类型的原生能力及可用性判断；测试未打开业务页时的发现，以及未登录、未授权、禁用和无本机宿主时不执行。
- [ ] 1.3 绑定工作区、运行、账号、组织与服务地址，定义最小结果投影和结构化错误；测试双栏隔离、账号切换、退出登录和能力禁用时不会返回旧数据或派发待执行写入。

## 2. 只读查询

- [x] 2.1 接入原生待办查询，处理本地日历区间、稳定续页和结果上限；测试今天零点、明天零点、夏令时、历史逾期、状态和负责人过滤、多清单去重，以及无结果与查询失败的区别。
- [x] 2.2 接入通讯录搜索与明确选人流程；测试同名、不可见联系人、有限候选及不同组织的候选引用不可复用。
- [x] 2.3 更新会话内工具说明并提供任务详情入口或编号回退；通过会话测试验证助手不会用内部会话待办代替原生任务，也不会把分页结果说成全量。

## 3. 用户确认与业务写入

- [x] 3.1 实现宿主生成的预览卡、不可变提案、一次性确认和结构化回执；测试取消、过期、修改参数、双击确认、伪造确认及 Full access 均不会绕过业务确认。
- [x] 3.2 接入日程创建，区分个人日程和含邀请的日程；测试目标日历可写、时间和时区校验、无参会人时不发邀请，以及预览值与实际写入一致。
- [x] 3.3 接入即时会议与预约会议的适配器；测试返回会议入口，区分创建和通知，默认不自动入会或开启摄像头/麦克风，未提供所需契约的操作不执行。
- [x] 3.4 接入面向明确单聊或群聊的纯文本发送；测试切换可见聊天后仍使用原收件会话、权限变化时拦截、服务确认才报成功，以及超时不自动重发。
- [x] 3.5 支持已确认的会议与 IM 组合，创建成功后用实际会议回执生成原生会议卡片，只发到预览中的会话；测试会议失败时不发卡片，IM 失败或结果未知时保留会议回执且不重复创建。
