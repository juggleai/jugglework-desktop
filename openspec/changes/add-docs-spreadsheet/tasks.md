## 当前验证结果

- 开发版 Desk 在云表格顶部三个点选择「在新标签页打开」，通过 Work 授权在独立文件浏览器打开同一工作簿。独立窗口内再次选择会在同一窗口新增标签，原标签和原视图保持打开。
- macOS ARM64 本地开发版 Desk 连接同机 Work 和 Docs。组织工作簿可以复制、另存为模板、从模板创建和复制为私有表格。源表、副本及模板实例分别保存，重启 Docs 后实例仍保留自己的修改和命名版本。
- XLSX 和 CSV 通过 Docs 一次性导入并在 Desk 打开。原件可逐字节下载，导出返回 XLSX、CSV 或 PDF 文件。PDF 也可从编辑器菜单下载到本地。
- 本地开发版 Desk 在组织首页新建独立 Workspace 的私有表格。宿主关闭视图前提交仍在编辑的单元格，等待 Docs 持久化确认。Docs 重启后，原私有表格按确认版本重开。
- 私有表格从开发版 Desk 移入回收站后停止目录展示与普通正文读取。恢复保留原表格及确认版本。
- 保存屏障最多等待 30 秒。未确认草稿按已授权主体与表格保留，授权访问恢复后可从应用恢复。
- ONLYOFFICE 仅用于本机原型验证。产品使用 FortuneSheet 云表格，Desk 的本地 Office 编辑与保存独立运行。
- 开发版 Desk 表格支持从详情页打开原生评论侧栏，已验证实际提交和评论链接高亮。已验证右键 C8 添加评论，提交后显示角标，收起侧栏后点击 C8 可再次打开原线程。插行后评论位置移动到 C9。IM 复用现有云文档卡片及授权交接。
- 开发版 Desk 验证私有表格在中文输入法组合期间发起关闭时等待写入确认，Docs 重启后可重开并读取原文字。边框工具保存后经重开和 XLSX 下载验证，Desktop 本地 Office 的创建、只读、故障恢复及宿主回归通过。
- 表格工具栏复用 FortuneSheet。开发版 Desk 验证百分比、小数位、删除线和下划线的保存与重开。
- 开发版 Desk 已在工具栏创建筛选并选定列值。刷新后条件仍生效，XLSX 导出并回导保留筛选范围、列条件及独立手动隐藏行。Web 两个测试账号已验证协作保存和 Docs 重启后重开。
- 开发版 Desk 验证云文档主页、普通文档和表格正常打开，主页未显示旧作者信息迁移提示。带高级筛选条件的 XLSX 导入可在警告弹窗取消，同一任务的重复提交被拒绝。重新选择文件并确认后打开新表格。
- Desk 本地文件上传跨 Electron IPC 返回表格转换报告。继续和取消均使用该报告对应的原请求，取消后重新上传使用新请求。实际开发版 Desk 上传验收确认发布后保持当前页面。
- 开发版 Desk 验证第二张工作表的连续范围评论可保存，重新打开带评论标识的地址会展开侧栏并滚动定位原选区。
- 开发版 Desk 实际切换应用明暗设置，云表格画布随之更新，工作簿版本保持原值。表格通过 Markdown AI 读写接口返回 `sheet_ai_unsupported`。
- 开发版 Desk 从工作簿的三个点菜单重命名，刷新后标题与 XLSX 导出文件名一致，链接和工作簿版本保持原值。
- 开发版 Desk 通过真实 Work 授权交接在独立 File Browser 打开表格，编辑、确认保存及重载后读取同一版本均通过。
- 开发版 Desk 在前一笔单元格保存等待回执时从宿主关闭表格。公式栏尚未按回车的输入被提交，宿主等待两笔确认后释放视图；重开时同一工作簿显示原值和已保存公式，结果为 42。
- 真实 Work 组织切换先确认当前表格。在待恢复草稿拦截切换时，页面和原组织都保留。以原操作 ID 保存后可切换，旧组织原生视图随之释放。
- 右侧文件面板打开两份工作簿后切换标签，原生实例 ID 保持原值，表格版本未改变。英文和简体中文工具提示、明暗画布随当前 Desk 设置更新。账户浮层使用原视图截图垫底，关闭浮层后复用原实例。
- 宿主回归测试覆盖本地文件与云文档的统一标签、缩放换算后的原生裁切、导航提示、原生视图焦点恢复，以及关闭时拒绝伪造或未确认的保存回执。
- 开发版 Desk 的 XLSX 转换取消和确认通过实际 Electron IPC；取消在本地结束，确认发布后保留当前页。Electron 拒绝一次 PDF 下载时未写入文件，下一次允许下载后生成可读中文 PDF，两次操作均保持表格版本。
- 隔离 Web 用两个成员验证重叠编辑时的未提交输入和原子拒绝。私有工作簿验证丢失回执、Docs 重启和合批发出前关页三种草稿恢复，版本没有重复推进。
