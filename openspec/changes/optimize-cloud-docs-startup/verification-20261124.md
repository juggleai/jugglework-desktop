# 云文档启动验收 · 2026-11-24

macOS 开发版 Desk 连接 `https://work.juggle.im` 和 `https://docs.juggle.im`。Docs Server 与 Web 代码版本均为 `3f0be7eae`。使用同一组织账号的三份私有测试文件，分别覆盖文档、FortuneSheet 表格和 PPTExt 幻灯片。

## 常规打开基线

关闭恢复和预热，在同一已运行的 Desk 进程中，从路由打开到观察到编辑器或画布挂载。每种格式 20 次。

| 格式 | 样本 | p50 | p95 | 失败 |
| --- | ---: | ---: | ---: | ---: |
| 文档 | 20 | 4.18 秒 | 4.56 秒 | 0 |
| 表格 | 20 | 4.98 秒 | 5.57 秒 | 0 |
| 幻灯片 | 20 | 4.81 秒 | 5.39 秒 | 0 |

主进程另有 Work runtime-config、launch、command-ready、首次可见及正文 `presentable` 诊断。前述统计的终点为编辑器挂载，正文诊断单独记录。

## 独立开关对照

每种格式在各列各测一次。主窗口刷新记录到原生编辑器可用；重启立即打开保留本机持久分区，从工作台可见后开始计时；预热命中从显式打开到已挂载原生视图被接管。

| 格式 | 刷新，恢复关闭 | 刷新，仅开启恢复 | 重启立即打开，预热关闭 | 预热完成后打开，仅开启预热 |
| --- | ---: | ---: | ---: | ---: |
| 文档 | 6.52 秒 | 3.61 秒 | 12.26 秒 | 0.30 秒 |
| 表格 | 7.73 秒 | 4.57 秒 | 17.04 秒 | 0.10 秒 |
| 幻灯片 | 7.71 秒 | 5.04 秒 | 9.19 秒 | 0.12 秒 |

- 恢复关闭时三次刷新均新建原生视图。仅开启恢复时，三个原生视图及其 JavaScript 实例均被保留，主进程记录恢复路径的 `presentable`，无新增 bootstrap。
- 忽略主窗口缓存刷新时，三种格式仍接回同一原生视图和 JavaScript 实例。各次耗时为 4.95、4.86、4.98 秒，原生 Docs 分区保持不变。
- 仅开启预热时，三个最近目标都在工作台内先完成隐藏加载。接管前宿主状态查询拒绝访问该实例；接管后均复用同一个原生视图，首次可见到正文 `presentable` 间隔为 27–37 毫秒。预热在显式打开前已消耗启动时间。
- 冷磁盘分组、按场景完整重复采样及 CPU、内存、流量门禁仍待验收。已测得的收益覆盖主窗口刷新和预热命中路径。

## 编辑与保存

- 用原生段落编辑器写入文档后刷新主窗口，恢复视图仍保有新内容。另一原生视图收到同一更新，Docs 的授权读取接口返回新内容，Desk 确认保存后关闭重开仍保留该编辑。
- 表格写入单元格，幻灯片修改演讲者备注。两种更新均可在第二个原生视图读到，Docs 内容接口分别读回对应修改，确认保存并关闭重开后均可读回。
- 同账号双视图覆盖内容传播与保存。真实双成员权限与同步仍待执行。

## 发布回滚

新加坡 Docs 已从 `3f0be7eae` 切换到上一发布目录，再恢复到 `3f0be7eae`。两次切换均通过服务健康检查及公网 Web manifest 版本校验。切换窗口前 Desk 收到本地保存确认，恢复后新打开三种格式，分别通过 Docs 内容接口读回回滚前保存的修改。发布间未应用数据库迁移。

## 云文档主页刷新复测

连接同一环境的开发版仅开启刷新恢复。主页直接刷新 3 次，先回工作台、刷新后再点云文档 3 次，两组均复用原生视图及其 JavaScript 实例。后者从点击到接管就绪为 2.98–4.43 秒。工作台稳定后另测一次，点击到宿主收到原生就绪事件为 0.76 秒。上述接管时间以宿主状态为终点。

恢复时只向 Work 申请一次新交接，运行配置请求耗时记录为 0。真实 Docs 的会话复核仍执行，Main 进入命令就绪的耗时约 0.22–0.32 秒。回归测试验证了 Docs 来源变更时保留视图不会被接管，普通打开仍读取运行配置。

## 两项能力默认开启

开发版 Desk 未设置恢复和预热环境变量，连接真实 Work 与 Docs 验证文档、表格和幻灯片。各格式预热命中及主窗口刷新各测一次，六次均复用同一原生视图。刷新到就绪分别为 3.94、4.07、3.83 秒。预热完成后点击至接管分别为 0.25、0.35、0.11 秒。

独立关闭验证覆盖每个开关设为 `0` 时另一能力仍可用。回归测试覆盖未认领预热在主窗口刷新后等待保存再清理，以及旧 Docs 返回 404 时回落普通交接。

真实 Work 与 Docs 环境中，同分区后台交接取消了尚未认领的预热，后台页随后正常就绪。隔离回归覆盖不同组织独立打开、保存失败阻止同分区交接、等待期间刷新使请求作废，以及切换组织复用同一保存确认并阻止旧请求继续打开。
