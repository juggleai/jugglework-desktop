# Desktop 云表格宿主

状态：实施规格。正文、协作、授权和格式以 [Docs design](../../../../jugglework-docs/openspec/changes/add-docs-spreadsheet/design.md)及 [API](../../../../jugglework-docs/openspec/changes/add-docs-spreadsheet/api-contracts.md)为准。

## 1. 复用与类型

沿用全页 Docs WebContentsView、工作区右侧统一文件 tab 和独立 File Browser；云表格与本地文件在同一 tab 条内，不新增一行“云文档”。新建入口在 Docs 页面内，不在 Desktop 重造文件树/工作表菜单。

所有定位使用当前 source/account/tenant/workspace/doc/file 身份；云表格描述为 `contentKind=spreadsheet`、editor=fortune-sheet、bodyFormat=fortune-workbook-v1。sheetId 只代表内部工作表。云文件与本地路径不同类型，不能按同名文件、后缀或全局“当前打开文档”绑定。

本地 `apps/server/src/office/engine.ts`、本地 Office SDK 及文件保存保持；它与云表格仅交换 XLSX/CSV 文件，不共享内存模型。Docx 原生云文档和 PPTX 附件仍走既有路线，云端 PPT 在线功能待表格完成后设计。

## 2. 加载、布局与缓存

表格由 Docs 前端按需加载源码构建的 FortuneSheet 包；Desktop 只加载当前配置的 Docs origin，不获取引擎地址、不注册新的 scheme、不启动原生转换进程。浏览器打开同一页面即可编辑，不能把 Electron API 当编辑依赖。

已打开 tab 切换复用就绪实例，不每次重新 launch/交接；全页云文档与后台请求继续复用现有受管视图池。HTTP 静态缓存按版本哈希持久化；正文、草稿及实例按来源/账号/租户/文档隔离。达到既有数量/内存上限时先执行该实例保存屏障再回收；后台页 idle 释放也不能销毁未确认编辑。

沿用 Docs 圆角、顶部空白拖动区/no-drag 按钮、导航 Tooltip 与账户浮层遮挡处理。语言/主题由 Desk 设置传入，只有英文/简体中文；不新增重复设置、客户端下载引导、AI 生成按钮或第二条云文档标题。打开后等待真正编辑器 ready，显示可取消/可重试的加载状态，不以页面 HTTP 200 当就绪。

## 3. 一次上传与分享

1. 工作区或独立窗口点击上传，先调用现有本地 Office 保存并等待；保存失败、AI 修改未完成或文件读取身份失效时不上传。
2. 沿用 stat/大小/摘要/lookup、选择打开已有/另存新文档、请求去重及固定租户。XLSX/CSV 由 Docs 表格模式处理，返回类型化结果；警告需明确确认。
3. 网络结果未知显示“上传结果待确认”，查询同 requestId；不得生成第二个请求号假装重试。
4. 只有原件、表格和目录提交完成才提示成功，保留本地文件页面；不强制打开云端。
5. 上传图标右侧显示分享图标，点击复制最近一次当前范围内有效结果的页面链接到系统剪贴板。链接不含交接凭据，不扩大权限。

原始文件和云表格此后独立。改本地不会改云端，改云端不会回写磁盘；重复另存上传生成新的云表格。下载或导出到工作区也是独立副本，保存位置/重名沿现有另存交互，不能静默覆盖原上传路径。

## 4. 保存和退出

统一退出协调分别等待本地 Office、AFFiNE 与 SheetHost。表格参与者使用 `closeRequestId + contextId + instanceId + fileId + lastOpId`：完成单元格/公式栏/中文输入法提交，立即 flush，等待本实例最后修改的持久化 ack，返回 confirmedRevision。现有 Desktop 消息桥与页面结果使用相同请求 ID 和超时预算，旧回执不能释放新视图。不能用 nbstore、本地磁盘保存或旧原生 checkpoint 判断云表格已保存。

关闭 tab、窗口、退出、切组织/用户和实例回收都走同一屏障，最长 30 秒；失败保留页面/当前身份和恢复草稿，允许重试或用户明确放弃尚未确认修改。放弃必须说明只影响本地待确认内容；已提交的云端修改不能被撤回成旧快照。源登录失效或撤权时遮蔽旧正文、停止读写并挂起隔离草稿。只有重新核验原身份及当前授权后才能恢复。退出时可清理缓存与连接，授权失效无需等待无法完成的保存。

切组织顺序为固定旧实例和目标→排空旧实例→关闭旧范围连接/视图→使用新范围；失败不能让 UI 已切到新组织而仍显示旧正文。其他协作者继续编辑不延长自己的保存等待。旧视图迟到回包只处理旧实例，不能替当前 tab 置为已保存。

系统强关只能恢复已 ack 内容，未提交草稿用于后续当前授权身份恢复；不能宣传浏览器缓存等于跨设备云端保存。正常保存状态不增加单独同步信息栏，异常通过既有提示和悬浮状态呈现。

## 5. 导出与能力

三个点“导出”只列服务端支持的 XLSX/CSV/PDF。Docs 为当前已确认版本生成 XLSX、CSV 或 PDF 文件。Desk 使用既有下载流程和中文文件名处理。PDF 提供当前工作表和整个工作簿两种下载范围。

AI 引用和选区在入队时固定到真实会话与资源，不按当前全局页面推断。表格 aiRead/aiEdit 未适配前明确拒绝；不能将云表格内容交给本地 Office AI 或 AFFiNE Markdown 回写。选区日后扩展为 sheetId/range/revision，仍复用现有标签和上下文机制。

表格在 Docs 视图内通过单元格右键菜单发起原生评论。提交后单元格显示黄色角标，点击单元格同步打开现有右侧评论栏。通知卡片沿用当前组织、文档和评论 ID 定位。

## 6. 兼容及验收

缺少 Desk 新标签能力的客户端沿用 Docs 页签。云表格编辑器由 Docs 页面加载；转换警告需要支持确认和取消的 Desk，或从 Docs 页面导入。模块关闭不影响本地 Office、IM、原生 Docs；既有表格可读降级及原件下载由服务端能力决定。

验收主窗口/右侧多 tab/独立窗口/Web，包含上传不跳转、分享隔离、热切换、中文输入、下载保存/取消、下载另存、租户切换、30秒失败和重启；协作收敛与格式保真复用 Docs 验收，不维护第二套规则。
