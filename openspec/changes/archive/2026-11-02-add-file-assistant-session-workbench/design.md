# 同一会话的两个入口

## 结构

```text
主窗口页面 ────────┐
                  ├─ 共享会话装配/控制层 ─ SessionSurface
文件窗口 AI 面板 ──┘          │
                         既有 Server 会话接口
                            │
                    既有 OpenCode session 与运行管理
```

共享的是代码、session identity 和服务端事实，不是跨进程共享 React/Zustand 内存。每个 renderer 保持自己的投影；显示时读取既有 snapshot/messages/status，接收既有事件更新，重连重新读取，不引入新的全局 cursor/outbox 协议。

## 会话身份

- 文件窗口由已有会话打开时，Main 固定 `{ workspaceId, sessionId }`。来源必须是本地工作区的真实已有会话；不能从“最近活跃会话”推断外部文件归属。
- 一个文件窗口中的文件标签共用此身份。不同 session 使用另一窗口，不引入 per-tab session 状态机。
- 文件标签切换仅改变当前文件上下文，不改变会话。提交时捕获文件/选区上下文，不把已接受任务改绑到随后选中的文件。
- 无归属的外部文件使用唯一默认工作区 `~/Documents/JuggleWork/FileAssistant`，Server 创建或恢复真实文件浏览器会话；创建会话不发送模型请求，同窗口标签共享会话。
- 真实文件会话开放原生 AI 编辑，复用现有采集、添加、发送、回执、定位与保存。临时无效会话仍不注入入口。

## 复用边界

- 从主窗口会话页面抽取可复用的会话装配/控制层；主窗口和文件窗口调用同一实现，不复制消息列表、composer、发送逻辑或错误处理。
- renderer 的布局差异、导航回调、文件上下文和 transport 作为显式宿主参数注入，不能要求文件窗口运行完整主窗口侧栏或工作区导航。
- 消息历史仍由现有 OpenCode session 保存；run admission、停止及交互仍由现有服务端管理。若某个能力仍依赖 renderer 唯一消费者，则文件窗口不启用该消费者。
- 草稿和未发送附件保持窗口局部；不会把 A 窗口草稿覆盖到 B。窗口重载/关闭遵循现有行为，不新增持久恢复承诺。
- 文件窗口支持立即发送和停止；忙时沿用既有拒绝反馈并保留本窗口输入。首版隐藏/禁用 follow-up enqueue、自动 drain、goal continuation 和 steer，不增加第二个自动调度器。主窗口已有能力保持原行为，不把其队列迁移为新系统。
- permission/question 两个页面读取同一既有请求；重复处理按服务端既有结果刷新，不由两个本地状态分别宣称成功。
- 模型/Agent 等提交选项沿用现有语义，不新增跨窗口设置协同或冻结协议。
- 文件窗口停止已绑定 run 前，Main 请求可信主窗口同步清除同会话 pending queue 和 preparing claims，收到有限时确认才发送 abort。listener 装在 root 生命周期，不依赖会话页面可见；未提交的自动 start/steer 在 claim 失效后取消，Office 引用 best-effort 释放不阻塞停止。不新增服务端队列或持久状态。
- 新会话首次保存请求审批时，既有权限模式表需要插入初始记录，权限版本从 0 递增到 1；不创建 grant。既有记录沿用降级清理与版本检查，不新增存储或 schema。

## Main 受限桥

- Main 登记真实 webContents 对象和顶层 frame，只接受登记窗口；窗口销毁或异步返回前失效的请求拒绝。
- renderer 不接收全局 token。Main 只为精确登记的 workspace/session 注入认证。
- 保留文件预览请求白名单；会话读取/发送/停止/交互另按实际复用 API 建立有限白名单，不开放任意 URL、路径、header 或 IPC。桥不是独立聊天协议，不复制业务规则。
- 既有 fetch 采用完整缓冲，不能直接用于无限事件流。事件桥只转发同一绑定会话所需事件，销毁时取消订阅；不另建持久事件库。
- 保持 context isolation、禁止页面导航和 Node 隔离；文件窗口启用 sandbox，有限 preload 打包为单文件 CJS，运行时仅依赖 `electron`。开发与安装包使用同一生成路径，不以放宽凭据或回退通用 IPC 解决兼容性。
- 本次不承诺对所有已有 Office/fileEditor 通道做 opaque handle 改造或绝对路径全面脱敏；不得扩大它们的现有权限。

## 界面与 Office

- 主窗口和独立窗口只有同一原始文件来源。Office 按真实文件身份复用 document/model，跨窗口只重挂已有 native view；文本按 workspace/path 共用既有编辑状态和保存入口，不创建窗口副本。
- 独立窗口文件工具栏更多菜单右侧显示机器人图标的深色“AI 对话”按钮，对已有本地会话和默认文件助手会话显示；展开后移除该入口，关闭面板后恢复。两种文件宿主均不显示上传、分享按钮。
- 面板顶部为机器人图标、JuggleWork、相邻的主窗口跳转箭头和右侧关闭按钮，高度与文件工具栏对齐；无额外底边线。分栏保留 1px 布局占位及外扩拖拽热区，常态、悬停和拖动均不绘制线条。
- 展开为真实分栏，文件容器变窄并更新原生 view bounds；窄屏在文档/会话间切换可见视图。消息复用已有 ScrollArea 自动隐藏圆角滑块，停止滚动后隐藏；输入栏保留 24px 侧边距、细边框和无投影圆角样式。
- 面板收起不停止 Server run、不关闭或重新打开 Office 模型。现有 dirty、撤销和关闭确认保持。
- 文件菜单遮挡原生页时，先取得并加载替代快照，给浏览器一帧绘制后再隐藏原生视图；收起菜单后，原生视图恢复完成才清除快照。普通文档状态通知不清除遮挡画面，迟到截图不得影响已恢复或后台的视图。
- “在主窗口打开”定位相同 workspace/session，不新建会话、不搬迁 Office owner。
- 文件选区仅使用现有 selectionRef 校验和提交能力；没有合法能力时禁用选区提交，不用路径或历史引用替代授权。
- 原生 AI 编辑浮层按真实宿主窗口准备和追加草稿；独立窗口使用同一会话的局部 Composer，添加或发送后展开面板。Main 只登记真实采集返回且属于本窗口文档标签的引用，校验、释放和提交均沿用此登记及既有 Server 校验；关闭共享模型同时确认两个宿主的未发送选区。
- 主窗口导航或关闭只取消本宿主的草稿准备请求，不使独立窗口的准备结果失效；迟到回复仍不可应用到新页面。
- Word 结构摘要省略软换行时，按已验证普通段落的 GCP 范围读取同一页面原文；保留 U+000B 等真实软换行，不猜测缺字。页面加载/提交状态及 SDK base_version 与原生 version 对应，Server 前后版本核对和完整结构、属性与预算检查保持有效。
- 选区编辑复用统一格式适配：Word 所选段落字符属性共用 1024 UTF-16 预算，未选独立图片按公开资源身份保留；Excel/CSV 读取固定范围及邻格，PPT 普通框允许 4096 UTF-16 多行文字。复杂未知结构和超预算内容仍不可执行，采集失败按实际原因提示。

## 存储

本次没有数据库升级。保持既有 runtime DB 路径、pending-operation schema 和 OpenCode 历史管理；原路径与会话关联使用 Server 的小型 JSON 记录，不保存第二份历史，不新增数据表。

## 默认工作区与外部文件

- 默认目录固定，零用户工作区冷启动先登记默认工作区再选择既有引擎启动目录。验收可显式覆盖为临时目录。
- 外部文件使用稳定 `external-files/<标识>/<文件名>` 键。读取、Office 工具、保存及交付回读共用原路径映射；未登记键不可回退为工作区磁盘文件，普通磁盘写操作不可覆盖该命名空间。
- 原文件已经属于存活聊天模型时沿用其归属，不复制模型。重启后恢复文件会话；只有会话确已删除才新建，网络失败不创建替代会话。
- 主窗口原生编辑区和聊天文件窗口的选择器允许用户明确选择工作区外原件；区外文件走同一本机登记和文件助手窗口，不改绑原窗口。区内文件保持原宿主，多选逐个路由，取消不登记。
- Main 保存已应用的普通聊天策略投影，包含部署、账户与组织身份，不包含凭据；独立启动可读取同部署策略，登出清除，损坏或缺失的登录策略不可放宽授权。
- 尚无策略缓存时，隐藏且启用 sandbox 的初始化页使用主分区、同一 index 页面来源读取已有身份和偏好，仅开放当前部署的身份、组织、桌面策略三个只读请求；完成即销毁，不装配主窗口、会话或队列消费者。账户变化使旧初始化失效，网络故障不放宽权限。
- 历史 model 中的 variant 单独交给模型行为解析，发送的 model 仅包含 providerID/modelID；首次选项快照及窗口内选择仍优先。
- 无主窗口时直接停止既有服务端运行；存在主窗口时保留同会话内存队列清理确认。
- 默认目录按当前 runtime 的 HOME 解析；开发模式沿用既有隔离 HOME，因此不会将开发数据写入正式版用户目录，不新建额外 profile。
- 普通文件请求在既有 admission 入口固定 documentId、pageId 与 engineFileId；内容查询、工具目录、编辑、Agent 保存及交付保存沿用同一目标。切标签和重复 admission 不改绑；旧模型失效后拒绝继续操作，不回退到新标签。
- 文件窗口不负责自报运行终态。服务端在引擎和委派任务均空闲时，使用本轮最新 assistant 的明确错误收尾失败运行；provider 错误无需 completed 时间，顶层 MessageAbortedError 保留 aborted，其余明确错误为 failed，不把错误认定为成功。

## 验收

检查真实双 renderer：同一 session 的历史/流式状态可刷新，发送不创建镜像 session，竞争发送由既有服务端仲裁，另一窗口可停止同一 run；文件窗口不启动第二队列消费者。安全、Office 布局和已有文件读写回归见 `release-gates.md`。

afterPack 检查 index、file-window、overlay、pet 四个 HTML 入口，本地 script/link/img 资源必须使用 `./` 相对路径并存在于包内目录。网页 `/assets` 绝对路径、缺失入口或缺失资源使打包失败；远程及 data 资源不作为本地文件解析。
