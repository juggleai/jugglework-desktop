# 实现状态与验收范围

## 已实现

- 主窗口与独立文件窗口复用 `SessionSurface`、runtime、draft sender、既有消息和运行接口；使用同一 workspace/session，不复制历史，不新增数据库表或升级 schema。
- Office 按实际文件身份复用同一 document、原生模型和编辑视图；异步文件检查后同步复查登记，两个入口同时首次打开相同文件或硬链接也只创建一个模型；文本按工作区及路径共用编辑状态。保存、回执和交付回读均指向原文件。
- 外部文件使用默认工作区 `~/Documents/JuggleWork/FileAssistant`，稳定键为 `external-files/<标识>/<文件名>`，真实会话关联保存在 runtime 的 `file-assistant.json`。不复制原文件，不把父目录登记为工作区；网络失败不创建替代聊天。
- 主窗口与独立窗口的外部文件标签均从同一登记解析原路径，用于另存为、最近文件及文件夹定位；从 Main 加入已有窗口的标签同样补齐原路径，普通工作区路径规则保持。
- 聊天所属文件窗口和主窗口原生编辑区的文件选择器支持区外原件，沿用本机登记在文件助手窗口打开，不改绑原聊天。区内文件仍进入原宿主，混合多选和取消有定向回归；“选择工作区外文件”本身不再作为失败场景。
- 默认目录沿用当前 runtime 的 HOME。开发实例实际目录为 `/Users/panyantong/Library/Application Support/com.juggleai.jugglework.dev/jugglework-dev-data/home/Documents/JuggleWork/FileAssistant`；正式版使用正常用户 Documents。
- 无主窗口时，已有登录可通过同一主分区、同一 index 页面来源的隐藏初始化页读取身份、组织、普通聊天策略和外观。初始化页启用 sandbox，仅开放三个固定只读 API，完成即销毁，不装配会话或队列消费者；文件窗口不持有账号凭据。登录失效清除策略，断网保留同部署缓存，不放宽权限。
- 普通文件任务在 admission 固定 documentId/pageId/engineFileId。切标签不改变已接收目标；模型失效拒绝操作。无主窗口时可停止运行，明确 provider 错误按权威空闲与本轮错误收尾，保留 failed/aborted 分类。固定版本引擎的精确用户拒绝权限工具错误，在本轮全部工具结束且根/委派任务空闲后以 aborted 收尾；普通工具错误不释放运行。
- 文件草稿保持窗口局部；首版无附件、enqueue、steer、goal 自动消费者。存在主窗口时，文件停止先确认清除同会话 pending queue/preparing claims；无主窗口时直接停止服务端 run。
- Main 校验真实 sender、顶层 frame、绑定会话、登记路径和窗口生命周期；限制请求、响应、重定向及订阅。文件窗口使用非持久独立 partition 和 `sandbox:true`，preload 打包为只依赖 Electron 的 CJS。
- 首次选项快照优先于历史，窗口后续选择独立；历史 model 的 variant 与两项模型身份分别恢复和提交，避免额外字段造成受限桥拒绝。
- AI 入口位于更多菜单右侧，使用机器人图标与深色按钮，展开隐藏、关闭恢复。面板显示 JuggleWork、跳转箭头和关闭按钮；两宿主移除分享、上传入口。分栏不绘制黑线，保留拖拽及键盘调整；消息滑块滚动后自动隐藏。
- 两宿主的 Office 采集、添加/发送、标签定位与移除复用既有引用契约。关闭共享模型同时核对两端草稿；文件目标失败和 admission 拒绝不清理已接受任务。
- Word 软换行由同一页面、对应原生版本的有界 GCP 原文补全；所选段落完整字符属性预算为 1024 UTF-16，未选独立图片按公开身份保留。Excel/CSV 按固定范围及邻格读取，PPT 普通框支持 4096 UTF-16 多行文字。复杂或超预算结构仍明确拒绝。
- 主窗口的 Office 草稿桥覆盖全部路由，登录页与设置页同样响应关闭检查；已有选区仍保护，路由变化使旧确认失效。
- clean 模型关闭前提交页面缓冲并重新读取 dirty；提交失败保留文档，已知 dirty 仍可明确放弃。既有 30 秒自动保存保持。
- Office 菜单遮挡采用画面交接：快照加载并绘制后隐藏原生页，原生视图恢复完成再清除快照；文档状态通知保留遮挡画面。快照迟到不影响已恢复或后台视图，文件模型不重建。
- 新会话首次明确保存“请求审批”时创建既有权限模式记录并递增版本；保持请求审批，不创建 grant，不新增表或 schema。
- 打包校验四个 renderer HTML 入口和包内相对资源，拒绝网页 `/assets` 绝对路径、缺失入口及缺失资源，避免 file:// 启动白屏。
- Composer/Lexical 在组合输入期间不提交任务、不抢候选导航或 Escape。文件宿主拒绝、模型选项及恢复提示有英中文案。窄栏文件修改摘要允许标题和按钮换行。

- 冷引擎启动 346.9ms；100ms 采样下 Bun+原生引擎进程树 RSS 最大 251MiB。`ps %cpu` 的进程自启动平均值采样最大合计 77.5%，不等同瞬时 CPU 峰值；宿主同时运行开发实例与构建，数值不作基准性能承诺。

## 未验收与能力边界

- 本轮 macOS ARM64 本机文件与 AI 清单完成；生命周期验证采用上述真实交互与明确回归的组合，不宣称每种格式、宿主和状态的全部排列组合均为原生人工点击。
- 包使用隔离配置且未复制账号凭据。真实 provider 的完成、编辑、停止、重连、permission/question 及子任务交互在使用已有登录的源码正式 main.mjs 验证；本地包验证文件操作、登录门禁、零工作区启动、权限首次保存及正常退出，不将其描述为已登录 provider 的包内验收。正式发布前仍需正常登录后的包内 provider smoke。
- Developer ID、公证及 DMG 安装仍未验收。
- 用户确认暂时没有 Windows x64、macOS Intel 实机验收与本项目团队的 Developer ID/公证配置，已记录为外部待验项；不能用本机 ARM64 或资源存在推断通过。
- Word 表格内/跨单元格文字、浮动对象、复杂/超预算结构，PPT 组内/旋转对象、SmartArt、备注、局部文字保真替换，以及复杂表格功能不在已开放范围。PPT 单页支持普通顶层文本框文字、公开样式及位置修改，保留简单表格与图片；文字选区仅改样式，整框替换会重置字符格式，需明确采用可恢复样式的单页路径。
- 未知写入后的阻断、可信核对与新引用接管由自动回归覆盖；尚无真实桌面未知写入后的人工核对 dialog 点击证据，不将普通切换确认或保存确认算作该场景通过。
- 某现有 provider 的 InvalidSubscription 为上游订阅状态；应用保留明确错误及重试能力，不修改账户或自动切换模型。
- 不包含跨窗口富草稿共享、未发送草稿新增持久化、队列重构、全部 opaque handle 或绝对路径全面脱敏。发布门槛仍以 `release-gates.md` 为准。
