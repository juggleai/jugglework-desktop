## ADDED Requirements

### Requirement: 漫剧工厂使用共享桌面应用外壳

漫剧工厂 SHALL 使用共享应用导航 Rail、圆角 inset 内容面、二级侧栏宽度与 resize 行为、页面顶栏高度及语义主题 token，不得引入独立的 Toonflow 或 Element Plus 视觉外壳。

#### Scenario: 在亮色主题打开漫剧工厂

- **WHEN** 用户在亮色主题打开漫剧工厂
- **THEN** 页面使用共享 `--app-page-bg`、`--app-list-bg`、`--app-topbar-height`、DLS 边框和文本 token
- **AND** 内容面与设置、插件、自动化及代码审查使用一致的 inset 圆角和窗口边距

#### Scenario: 在暗色主题打开漫剧工厂

- **WHEN** 用户切换到暗色主题
- **THEN** 项目侧栏、画布、检查器、节点、菜单和状态提示通过现有语义 token 自动映射
- **AND** 不保留硬编码的亮色白底或 Toonflow 品牌控件样式

### Requirement: 漫剧工厂首页与项目工作区遵循共享响应式布局

漫剧工厂 SHALL 在项目首页使用响应式灵感输入区与项目卡片，并在打开项目后使用全尺寸画布、浮动工具条和可收起创作助手，不得通过永久项目侧栏挤压画布。

#### Scenario: 用户打开漫剧工厂首页

- **WHEN** 当前路由没有选择漫剧项目
- **THEN** 页面显示灵感输入卡和响应式项目卡片列表
- **AND** 不显示永久项目侧栏或空白画布

#### Scenario: 用户打开漫剧项目

- **WHEN** 当前路由选择了一个有效项目和分集
- **THEN** 点阵画布使用共享 inset 内容面的可用空间
- **AND** 项目、分集、工作模式、模型和保存状态通过浮动工具条提供
- **AND** 工作流、生成、文本与交付能力通过可收起的右侧创作助手提供

#### Scenario: 窗口宽度不足

- **WHEN** 窗口宽度不足以同时容纳画布和创作助手
- **THEN** 创作助手以可开关的底部抽屉呈现
- **AND** 画布工具条保持可用且不被抽屉永久遮挡

### Requirement: 创作入口与画布空状态提供真实操作

漫剧工厂 SHALL 参考空间化创作工作台的信息层级提供灵感输入、项目卡片、空画布快捷入口和画布控制，同时保持 JuggleWork 品牌、语义主题和真实能力边界。

#### Scenario: 用户从灵感创建项目

- **WHEN** 用户填写项目名称、工作区相对目录和创作意图并创建项目
- **THEN** 创作意图被幂等地初始化为首集来源文本
- **AND** 页面切换、响应不确定或重试不得丢失意图、覆盖已有分集或重复创建内容

#### Scenario: 用户打开空画布

- **WHEN** 当前分集画布没有节点
- **THEN** 页面说明可以双击画布创建文本节点
- **AND** 图片和视频快捷入口只在相应模型能力可用时启用

#### Scenario: 用户操作画布视图

- **WHEN** 用户执行缩放、重置或适应画布
- **THEN** 控件真实更新并持久化画布 viewport
- **AND** 适应画布根据所有节点边界和可用画布尺寸计算视口
