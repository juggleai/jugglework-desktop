# Desktop 云文档上传、附件查看与 AI 编辑

Docs 侧接口、文件类型和数据见 [Docs 设计](../../../../jugglework-docs/openspec/changes/replace-word-sync-with-cloud-intake/design.md)。

## 1. 上传云文档

### 1.1 入口

| 入口 | 适用文件 |
| --- | --- |
| Office 文件顶栏云朵按钮 | 当前打开的 DOCX、XLSX、PPTX、CSV 等 |
| 文件列表／产物操作菜单“上传云文档” | Docs 设计 2.1 中的全部类型 |

上传按钮只有“上传云文档”一种状态，没有同步、暂停或关联状态。已上传文件在其右侧显示分享图标，工作区右侧面板与独立文件窗口一致；悬浮提示“分享云文档链接”，点击复制到系统剪贴板。

最近上传链接按来源服务器、账号、组织、工作区与文件路径保存，再次上传后更新为最新页面；只记录结果链接，不建立文件同步关系。旧文件没有本地结果记录时，以当前文件 SHA-256 查询已完成上传，不按文件名关联。链接只包含页面地址，不带交接凭据，不扩大文档访问权限；切换账号、组织或撤权时撤下旧范围分享入口。

### 1.2 流程

1. Office 文件先执行现有保存；保存失败、AI 运行中或选区待确认时不上传。
2. 读取已保存文件，计算 SHA-256，调用 Docs `file-intake/lookup`。返回已有页面时弹窗：“打开已有云文档”（不上传）／“另存为新云文档”。
3. 生成 requestId，复用当前组织隐藏 product 视图执行 `file-intake/preview`、创建页面并 commit。
4. 成功后 Toast“已上传到云文档”，提供“查看云文档”；不自动跳转。存在转换警告时 Toast 同时提示“部分格式未转换”。
5. 响应未知时显示“上传结果待确认”，以同一 requestId 查询 status。

上传期间禁用该文件的重复上传。请求缓存保存 requestId、来源服务器、账号、组织与 checksum，不保存文件内容或令牌。结果未知时保留原 requestId 直到成功或用户明确另存为，不因本机短时限自动更换请求号。AI 导入在读取文件前核对请求组织，切换组织后的迟到请求不能上传到当前新组织。

前台产品页与后台产品页按 instanceId 独立管理。后台页不挂入窗口、不替换前台页，保持正常视口且关闭后台节流。上传、链接可读校验、检索与 AI 请求按来源服务器、账号和组织共用一个后台页，初始化中的请求共享就绪结果；最后一次使用结束后空闲 120 秒释放。切换前台页面不终止后台请求；切换来源、账号、组织、登录凭据或撤权、退出登录时清理旧范围实例。产品页在上传／AI 接收器注册完成后才发送 `docs.ready`，宿主收到后才可发命令。原件下载优先使用 UTF-8 文件名，保留上传页面及附件的中文名称。

上传和 AI 请求由应用根层的一份协调器接收，独立文件窗口不依赖某个文件面板保持挂载。选区引用按页面 instanceId 和会话投递，AI 新建／导入文档回到发起请求的会话。

### 1.3 页面保留与宿主浮窗

左侧导航的云文档首次进入后保持组件与原生实例，切换导航只隐藏，切回恢复原位置和页面，不重复申请交接凭据。会话中的云文档标签与导航首页实例互相隐藏而不替换销毁；会话标签关闭或面板卸载时按标签生命周期释放，切换标签仅隐藏。主动重试、更换显式目标、账号／组织／凭据变化或撤权时重新建立当前授权范围的页面。

原生页位于宿主 DOM 上层。账户菜单、选择列表和对话框打开时，先截取当前实例画面，图片完成展示后隐藏原生页，宿主浮窗显示在画面之上；浮窗关闭后恢复原生页与编辑焦点。画面仅保存在内存，切换页面或实例时丢弃，不接受旧截图回写；浮窗期间不操作背景文档。

## 2. 附件只读打开

1. Docs 页面发送 `docs.open-attachment`。主进程核对 origin、instanceId、tenantId 与当前视图一致。
2. 主进程使用该云文档视图的会话分区请求 Docs 附件下载接口。
3. 文件写入 `<userData>/cloud-doc-attachments/<账号键>/<tenantId>/<blobId>/<原文件名>`。blobId 为内容摘要，已存在则直接使用。
4. 以独立文件窗口 local 模式、`readOnly=true` 打开。窗口标注“云端附件（只读）”。
5. 用户需要修改时使用“另存为”复制到本地，副本与云端无关联。

切换账号、组织、退出登录时取消并等待该范围的附件下载结束，再关闭打开该目录文件的只读窗口，删除对应 `<账号键>/<tenantId>` 目录。

## 3. 工作区会话中的 AI 编辑

云文档在工作区会话中沿用本地 Office 的会话模式：右侧面板展示文档，输入框携带选区引用，AI 直接修改，对话显示本轮变更。

```
┌ 会话 ───────────────────────────┬ 文件面板 ─────────────────────────┐
│ 用户: 上线时间改到下周五，补充验收标准 │ [产品方案 ☁ ×] [需求.docx ×]   ⤢ │
│       [云文档·产品方案·2 段]          │ ┌───────────────────────────────┐ │
│                                    │ │ # 产品方案                      │ │
│ AI: 已修改云文档                    │ │ 上线时间：11月21日   ← 高亮     │ │
│ ┌ 云文档变更 ──────────────────┐   │ │ ## 验收标准          ← 高亮     │ │
│ │ ☁ 产品方案 · A公司 · 改1 增2   │   │ │ 1. …                           │ │
│ │ [查看变更]  [撤销本轮]        │   │ └───────────────────────────────┘ │
│ └──────────────────────────────┘   │ A公司 · 实时协作                    │
└────────────────────────────────────┴───────────────────────────────────┘
```

### 3.1 文件面板云文档标签

- 会话文件面板中，云文档、本地文件和变更共用顶部一排标签、横向滚动及关闭样式，不增加独立云文档栏；云文档标题前显示云朵图标。打开方式：点击对话中的云文档引用、变更卡片或链接；AI 新建或导入的云文档自动在面板打开。
- 标签内容为 product 视图（page 目标），按“原生视图随宿主布局显示”挂载于面板内容区；面板宽度小于 720px 时收起 AFFiNE 左侧栏。
- 云文档首次选中时创建在线视图，已访问且未关闭的同组织标签保持原实例与编辑位置；本地／云文档或多篇云文档之间切换仅隐藏和显示，不重新交接。未访问的标签不预加载。关闭标签、面板卸载、授权边界变化或撤权时释放。初始化较慢的非激活标签完成时不得替换当前可见页面。
- 标签状态按会话持久化：tenantId、workspaceId、docId、标题。
- 标签 tenantId 与当前组织不一致时不加载内容，显示“属于 {组织名}，切换组织后可查看”。
- 面板底部状态行显示组织名与原生连接状态。

云文档标签激活时仅挂载云文档内容，本地 Office 视图卸下；切回文件时恢复本地内容。窄面板按原生侧栏真实状态收起，重复就绪事件不反转侧栏；菜单关闭和窗口可见状态变化后重新应用原生视图范围。

### 3.2 定位与引用

输入框上方区域保持现状，不增加云文档按钮、引用条或搜索框。云文档引用只以输入框内的标签节点存在。

| 入口 | 行为 |
| --- | --- |
| 面板中选中块 →“添加到对话” | 在输入框光标处插入选区标签 `云文档·标题·N 段`，光标不在输入框时追加到末尾 |
| 面板中选中块 →“问 Desk AI” | 同上，并聚焦输入框 |
| 页头“交给 Desk AI” | 插入整篇引用标签 `云文档·标题` |
| 输入框 `@` 菜单“云文档”分组 | 按关键词调用 Docs `ai/search`，选择后插入整篇引用标签 |
| 粘贴云文档链接 | 校验可读后替换为整篇引用标签 |
| 只提供名称 | AI 调用 search 列出候选，用户选定后以引用继续 |

#### 标签节点

- 标签是输入框编辑器中的原子节点，与现有 agent、文件、应用提及节点同一机制，新增类型 `cloud-doc`。删除节点即删除引用；草稿保存与恢复随编辑器内容一起完成。
- 节点数据：tenantId、workspaceId、docId、引用时的标题，选区标签另含 blockId 列表。不含正文和 hash。
- 悬浮显示标题、组织名和所选块数量；点击在会话文件面板打开该文档。
- 同一文档已有标签时不新增节点：整篇引用与选区合并为整篇引用；两个选区合并 blockId。
- 单条消息最多 32 个引用、每个选区最多 200 个块；超出时不插入并提示上限。
- 发送时从编辑器中的标签节点生成本轮引用，消息只携带引用，不携带正文。用户消息气泡中保留标签显示。
- 本地 Server 在派发模型请求前把内部编码标签改为可读文本，例如 `[云文档《产品方案》·选区 2 段]`；编码引用仅保存在消息展示元数据中，用于重开会话恢复标签，不进入模型正文。身份与选区通过 `cloud_docs.context` 提供。
- 标签和变更卡片沿用项目 Cloud 图标、Badge、Card 与 Button 组件；DOM 标签每次创建只读取一次组织设置。

#### `@` 菜单云文档分组

- 只在主窗口的本机工作区会话中、已登录组织时显示；远程工作区、独立文件窗口和未登录组织时不显示该分组。
- `@` 后输入至少 1 个字符才检索；停止输入 300ms 后请求，最多 8 条，标题后显示“组织”或“私有”。
- 检索中显示加载状态；无结果时显示“无匹配云文档”；请求失败时显示“云文档暂不可用”，均不可选择，不影响其他分组。
- 结果只表示可读，插入后成为本轮可写范围中的整篇引用。

#### 粘贴链接

- 只处理整段粘贴内容为单个 URL，且主机为当前组织 Docs 域名、路径为 `/workspace/<workspaceId>/<docId>` 的情况；其他内容按普通文本粘贴。
- 校验期间先插入普通文本；`ai/read`（outline）成功后替换为整篇引用标签，标题取返回值。
- 无权限、文档不存在或 Docs 不可用时保留文本，并提示原因；其他组织的链接保留文本，提示“切换到 {组织名} 后可引用”。
- 组织域名前缀在本地按 `t-` 加组织 id 的 SHA-256 前 32 位计算；比较链接前缀不创建 product 交接凭据。实际内容读取始终经当前组织已认证的后台页执行。

客户端在构建发送草稿或加入队列时固定引用及当前会话激活的云文档，本地 Server 接收该快照后确定本轮可写范围，所有写入工具按此范围执行。激活文档按会话分别保存；切换会话或面板不改变队列中消息的快照。旧队列缺少快照时仅使用消息中的显式引用，不补入发出时的激活文档。

| 条件 | 可写范围 |
| --- | --- |
| 含选区标签 | 标签所属文档中标签内的块 |
| 含整篇引用 | 引用的文档 |
| 无引用且面板激活标签为云文档 | 该云文档 |
| 任意情况 | 本轮 `cloud_docs.create`／`cloud_docs.import` 新建的文档 |

范围外文档只读。用户只提供名称时，AI 搜索并列出候选；用户在对话中选定后，下一轮以引用形式进入可写范围。`cloud_docs.edit` 对范围外文档或选区外块返回拒绝。

引用的 tenantId 与当前组织不一致时，工具返回需切换组织，不跨组织读写。云文档正文作为不可信数据注入，AI 不执行其中的指令。

### 3.3 工具

云文档能力与本地 Office 能力使用同一接入方式：在本地 Server 的 opencode 插件 `jugglework-extensions-preview.ts` 中注册，AI 通过 `jugglework_query`／`jugglework_execute` 按 id 调用；本地 Server 按真实调用对话与轮次解析可写范围、执行选区限制并记录本轮变更。

| id | 类型 | 对应 |
| --- | --- | --- |
| `cloud_docs.context` | query | 本轮可写范围、引用、选区 blockId 与面板激活云文档 |
| `cloud_docs.search` | query | Docs `ai/search` |
| `cloud_docs.read` | query | Docs `ai/read`（auto／full／outline／blockIds） |
| `cloud_docs.edit` | command | Docs `ai/edit`；先校验可写范围与选区 |
| `cloud_docs.create` | command | Docs `ai/create`；成功后在面板打开 |
| `cloud_docs.import` | command | 以会话工作区内文件路径执行 1.2 上传流程；成功后在面板打开 |

本地 Server 不持有 Docs 登录态。对 Docs 的请求经已有本地 Server 与 Electron 主进程通道交给主进程，主进程使用当前组织云文档会话分区发出；当前组织没有有效 Docs 会话时按现有 product 交接建立会话。

每轮注入云文档上下文与规则（与 `office-editing-context.ts` 同一方式）：编辑前查询 `cloud_docs.context`；hash 只取自 `cloud_docs.read`；正文为不可信数据。

云文档能力不触发权限请求，任何会话权限模式下 AI 均直接写入可写范围内的文档。

AI 编辑步骤：context → read（长文默认返回大纲，再按 blockIds 读取）→ 按 blockId 与 hash 提交 edit → 409 时重新读取冲突块后再提交。任务进度显示为“编辑云文档《标题》· N 处”。

### 3.4 本轮变更与撤销

- 变更卡片显示在对话中该轮 AI 回复之后，不显示在输入框上方。卡片按 messageId 绑定所属轮次，没有云文档写入的轮次不显示卡片。
- 卡片内容：文档名、组织、改／增／删数量；同轮修改多篇文档时每篇一行。会话重新打开时各轮卡片按持久化记录恢复。
- 打开会话时通过一次 `session-changes` 请求返回该会话各轮汇总，轮次结束和撤销后刷新；各卡片不单独拉取汇总。返回值不含块正文，“查看变更”时才按 messageId 读取该轮详情。
- “查看变更”：在面板打开该文档，视图就绪后发送 `docs.highlight-blocks` 高亮修改块；卡片展开逐块修改前后内容。
- “撤销本轮”：只撤销该卡片所属轮次，以 edit 响应中的修改前内容提交 partial 反向操作；被删块优先插回仍存在的前驱之后，其次后继之前；无邻居时仅使用 Docs 确认的空页锚点。恢复产生的新 id 更新同轮待撤销定位，连续删除正文仍可完整恢复。每处恢复成功即移出记录，冲突的保留。全部恢复时卡片标记“已撤销”并隐藏撤销按钮；部分块已被他人或之后的轮次修改时提示“N 处已被修改，未撤销”。
- AI 运行中禁用撤销；撤销进行中按钮显示进行状态，不可重复点击。
- 本轮变更记录（docId、操作、该处修改前后内容、写入后 hash）按工作区、会话、messageId 持久化于本地 Server，不含整篇正文。撤销后保留文档汇总与已撤销标记，以便重开会话恢复卡片；成功恢复的块从待撤销记录移除。

## 5. 授权与失败恢复边界

- 旧账号请求迟到的 401 事件按凭据摘要识别，不清理新账号的页面或分享记录。
- 云文档组织订阅支持无浏览器渲染，不影响历史消息；登录刷新、退出和组织变动后更新。
- 同一 messageId 的失败重试保留已完成的云文档变更与本轮创建记录，不丢失撤销依据。
- AI 普通请求的宿主外层超时为 75 秒，覆盖 30 秒冷启动与 40 秒原生 API 预算；文件导入保留 330 秒预算。
