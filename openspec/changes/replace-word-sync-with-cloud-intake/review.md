# 云文档代码审查结论

范围：Desktop 渲染层、Electron、本地 Server、Docs 前后端及 Go Server 的本次云文档改动。

## 已修复问题

| 等级 | 问题 | 当前行为 |
| --- | --- | --- |
| P1 | 迟到的 AI 导入使用切换后的当前组织 | 读取本地文件前核对请求组织，不向其他组织上传 |
| P1 | 多段替换只记录第一段，邻接操作的新块归属不完整 | 原生解析计算片段块数，落盘前确认归属，返回各操作全部生成块 |
| P1 | 首段／全部正文删除后无法撤销，恢复后块 id 变化导致连续撤销失败 | 前驱、后继及仅空页有效的插入锚点定位；恢复后的新 id 更新待撤销记录 |
| P1 | 转换半成品被当成完成页，failed 上传可尝试提交 | 原件附件作为完成标记；半成品用同一 pageId 重建；commit 只接受 preparing 且含原件的页面 |
| P1 | 下载中撤权后附件仍可能落盘并打开 | 取消并等待该范围任务结束，再关闭窗口及清缓存 |
| P2 | 历史消息渲染缺少订阅的服务端快照 | 无浏览器快照为空；登录和组织更新后重新订阅 |
| P2 | 同消息失败重试清空云文档变更与新建记录 | 重试保留原记录和撤销依据 |
| P2 | 无标题长文大纲缺少可用块定位 | 正文分节提供全部 blockIds，可按 id 读取尾部 |
| P2 | 外层 AI 超时短于冷启动加原生请求预算 | 普通 AI 请求预算为 75 秒，导入为 330 秒 |
| P2 | 未知上传结果的 requestId 短时失效 | 结果未知时保留请求号，成功或明确另存为才更换 |
| P2 | 附件下载头丢失中文名 | UTF-8 下载头保留原名，ASCII 文件名作为兼容回退 |
| P2 | 旧账号迟到撤权事件清理新账号页面 | 按当前凭据摘要匹配撤权事件 |
| P2 | 文件窗口测试夹具缺少新增的异步剪贴板接口 | 夹具补齐导出；真实沙箱测试覆盖复制行为 |

## 验证

- Desktop 云文档及相关消息渲染回归：62 项通过。
- 本地 Server 云文档与 Office 回归：291 项通过，56 项真实引擎集成用例跳过。
- Docs 上传、附件、原生块编辑：22 项通过。
- Electron 附件取消及独立文件窗口沙箱：5 项通过。
- Go Server Docs 服务测试通过。
- Desktop App、本地 Server、Electron、Docs Backend、Core 与 Web 完整类型检查通过。
- Desktop App、Docs Web 与 Server 源码构建通过。
- Desktop 与 Docs 的本次 OpenSpec 严格校验通过。

## 未关闭事项

1. Desktop 全量测试中仍有 10 项基线已有的断言失败及 3 处基线已有的 IM SDK 测试环境初始化错误；本次改动没有新增失败。已有失败涉及嵌入会话、演示文件 MIME、显式重试、自动化、登录回退、插件布局、绘图、导航和工作区外壳。全量测试不能标记全绿。
2. 全格式 Office 附件只读打开，以及另一成员在线可见的真实协作与 AI 编辑联合验收仍未完成，分别保留在 Desktop 3.4／4.7、Docs 5.1／5.2。
3. 本次源码审查与构建不代替生产发布或真实 AI 提供方的完整联合验收。
