# 开发版统一共享交互

- 桌面、普通窗口与白板统一等待本地 `_screen` 发布进入 `PUBLISHING`，失败、取消、超时不进入正在共享状态。
- 发布成功后会议窗口隐藏而不销毁；原小窗转为工作区底部共享工具栏，显示「你正在共享屏幕」、停止共享、展开会议、音视频与可用的标注控制。
- 展开会议仍保留共享工具栏；停止共享恢复会议窗口。
- 白板迁到独立同源原生窗口，通过主窗口 React portal 保持单一媒体与会话；关闭白板停止白板共享。白板发布前显示连接状态，成功后显示共享中。
- 此轮尚未做真实双端及原生窗口端到端验收，不表示标注层级故障已修复；需重启开发版加载主进程变化。

## 共享栏样式修正

移除临时行内布局，添加独立横向样式，覆盖旧 mini 的 column、状态文字固定高度和图标按钮固定宽度；停止共享使用自动宽度按钮。独立 Electron 620×56 样式对照验证所有控件无裁切、无垂直溢出，清理确认；前端类型检查通过。未替代真实会议视觉验收。
