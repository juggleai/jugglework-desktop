## 本轮修复与证据能力

- `meeting-window-p0.ps1`：新增 `IsWindowVisible` 自报字段，不改输入协议、目标几何或生产入口。
- `meeting-window-p0-hybrid.ps1`（新增）：不走 WinForms 的合成原生目标，可自最小化、自改宽、生成自己的可见遮挡窗；仅创建/销毁自有窗口，全程无输入。
- `meeting-window-p0-hybrid-place.ps1`（新增）：只对调用方自有墨层 HWND 做一次 `SetWindowPos`，插到目标正上方；结果仅作提示，通过与否仍由只读观察器复核。
- PowerShell 承载的目标会带一个不可见、零面积同进程窗口进入 Z 序，使默认创建顺序无法严格相邻；自有层主动定位后再复核是当前可行路径，不是放宽判据。该夹层角色仍未识别，不能按进程归属放行。
- 枚举仅请求 `types:['window']`、零缩略图，不抓取无关窗口画面；唯一 HWND 十进制字符串精确匹配 + 私有随机标题双校验，真正请求捕获前重新枚举。标题不用于猜 HWND，不经 JS Number 传句柄。
- 新入口通过隐藏的沙箱 viewer 调用 getDisplayMedia，等待至少3次实际回调并检查最后一次画面；只回传合成统计和有限失败阶段。默认启动夹具局部动画，`--static-target` 保留静态对照。未加入独立原生观察进程对目标生命周期/采集前后身份的完整认证，不是产品认证方案。
- 清理计划：先销毁自有viewer、结束子进程stdin，只有 `closed` + exact child exit0 + 无signal/无强制终止才报confirmed；5秒EOF宽限后只终止本轮child，强制终止永远unconfirmed，随后1.5秒最终退出兜底。默认loader启动、ready超时、迟到回复拒绝与失败分支均有替身回归，真实故障矩阵未完成。
- compositor仅验证已给定BGRA位图的指定像素覆盖和非墨区不变。不透明覆盖具有幂等性，叠一次与两次可完全相同，新增测试明确证明此限制。`verifySingleOverlay` 保留原名称但注释与报告不再承诺“实际只叠一次”。有界输入校验拒绝非法尺寸、offset、无限thickness和过量栅格工作。
- 历史一轮诊断曾把其他窗口标题写进本机临时输出，违背最小化诊断约束；已删除代码中的标题输出。报告不复制标题/原始日志，临时文件未作为交付附件，未删除或改写历史记录来掩盖问题。

## 给主 agent 的四项决定

1. **可支持范围**：Windows x64、单屏100%上，已复现：纯Win32被动几何/严格相邻、合成单窗标记流、被动墨层正常相邻/呈现/无回灌、遮挡层级、最小化/改尺寸撤层、100%帧映射，以及 A4 穿透/绘制/遮挡点击三种真人模式（墨层与目标计数均符合预期）；不能据此开放产品单窗标注。
2. **须拒绝/尚未认证**：未经可靠来源与生命周期认证、几何/DPI不精确、topmost/失序或读回不可信时不得启用标注输入；窗口样式、跨屏、热区、遮挡和最小化恢复尚无本轮足够证据。不能按PID放行夹层、容差吞差值、整边放行或复位目标尺寸。
3. **可移植的夹具实现**：原生被动探针、严格匹配/迟到回复守卫、有界清理与98项回归可供重现。新诊断入口不能作为完整A3。`ImmDisableIME(-1)`只限原生专用探针，不移入Electron或产品。
4. **只能在B验证的项**：产品入口门控与会话隔离、真实ZEGO发布/订阅连续性与远端90%性能门、实际生产签名包及安装/卸载。真实输入矩阵在A4也必须完成，不能推迟成B专属。

## 后续顺序与门禁

1. 用户已核对无测试窗并授权恢复；恢复后的四轮均确认 EOF 清理。历史超时仍未获得当轮清理证据；任何新一轮未确认清理立即停止重跑。
