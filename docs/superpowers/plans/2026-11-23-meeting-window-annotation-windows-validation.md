# Windows 单窗口标注：真机验证与实现交接计划

> **给执行 agent：**在 Windows 已登录的交互式桌面里执行。按 `executing-plans` 逐阶段推进，使用复选框记录结果。这个文档是验证方案，不是开启产品功能的授权。

**目标：**一次交接收齐所有必须在 Windows 机器上取得的证据。A 完成后，主 agent 可在 macOS 上按证据实现 Windows 产品路径；B 在产品分支准备好后回 Windows 正式验收。

**架构：**先在隔离夹具中分离验证来源身份、采集坐标、Win32 窄边、Electron 笔迹、输入与清理；再验证产品门控、会话状态、发布链路与安装包。后续实现不要求重新选源或 ZEGO 换轨。

**技术栈：**Windows PowerShell 5.1 / Win32 / DWM（PMv2）、仓库锁定的 Electron / Chromium、Node、Canvas 2D、ZEGO、Windows PE / Authenticode。

## 通用约束

- 规格取 `openspec/changes/add-meeting-window-annotation/{design.md,tasks.md,specs/meeting-window-annotation/spec.md}`；本计划补充旧的 `2026-11-20-meeting-window-annotation-windows.md`，不替代规格。只做主讲人单窗口标注；参会人标注二期、普通窗口共享、整屏标注、白板和服务端不在改动范围。
- A 只改独立夹具和配套测试；只创建、移动或销毁自有窗口，不改被测外部窗口、不设全局置顶、不抢焦点、不注入输入或装全局输入钩子，不采集整个桌面。真实点击由人操作或经授权的本机交互工具在专用测试桌面操作，不以 `PostMessage`、合成 DOM 事件或热区标志替代。未经同意不改变系统缩放或桌面布局。

- [ ] 在相应架构的干净 Windows 账户普通权限安装：检查 helper 可启动，不依赖源码目录/开发 PATH，路径有空格或非 ASCII 也可用；出现 SmartScreen/安全软件阻断则记录，不绕过。分别测默认关闭、实验开关启动、实际捕获/显示/输入冒烟、helper 丢失或校验失败安全降级、应用退出清理及卸载。只有编译机没有目标架构真机时，PE 检查与安装实测分开记录。

## 交接与放行规则

- **A 结束即交回主 agent**：先交实测支持范围和最小重现，即使 B 尚未开始。不要让 Windows agent 等着产品代码，也不要把 B 伪装成夹具通过。
- **B 结束才做产品放行判断**：支持环境上的真实输入、同轨双端连续性、90% 性能门和对应签名包验证均须有证据。未覆盖的窗型、DPI/跨屏组合、架构和权限状态不能泛化为支持。实验开关默认关；是否扩大范围/默认开启另行决定。
- 从规格到用例：入口 → B1；真实窗、对位/跟随 → A1–A3/B1–B2；正常缩放、平移和尺寸退出 → A2/A4/B1–B2；遮挡、最小化、关闭 → A1/A3–A4/B1–B2；合成、不黑、留最后帧与 90% → A5/B2；发行 → B3。
