# 产品与交互设计

## 1. 用户目标和范围

用户可以从会议工作台、组织群和单聊发起同一种会议；会议号、详情、成员、日历、权限及会中体验一致。会议来源只影响默认标题、邀请对象与入会资格，不产生三套房间系统。

首期支持桌面端同组织会议，不提供匿名入会、跨组织会议、电话拨入、收费升级入口。会议号用于定位会议，不能替代身份权限。人数和时长限制读取组织能力，不能把截图中的「25 人／60 分钟」当作既定限制。

## 3. 信息架构

```text
左侧导航                 会议主区域
  消息                    首页：快捷操作 + 今日会议 + 进行中会议
  通讯／通讯录             日历：日 / 周 / 月、我的会议 / 群会议筛选
  会议                    历史：我主持 / 我参加 / 搜索
                          详情：时间、来源、人员、状态、操作

单聊／群聊 → 发起会议 ─┐
会议首页 → 快速会议 ───┼→ 会前预览 → 独立会议窗口
会议卡片／横幅／日历 ──┘
```

导航的可见性与当前组织身份和 IM bootstrap 绑定，再叠加 `meetingEnabled`。能力解析期间不沿用上个组织的入口。暂时断网仍保留已确认有权限的会议入口，显示离线状态；这与组织切换期间隐藏入口不同。红点用于待处理邀请，不随每条会中消息增长。

### 3.1 首页线框

```text
┌导航┬──────────────────────────────────────────────────┐
│消息│ 会议                    [首页] [日历] [历史]       │
│通讯├──────────────────────┬───────────────────────────┤
│会议│ [加入会议] [快速会议] │ 11 月 6 日 周五    [今天]    │
│    │ [预约会议]           │ 09:30 产品评审  进行中 [加入]│
│    │                      │ 14:00 项目周会  待开始 [详情]│
│    │ 当前会议 [返回会议]   │ 无安排时显示「今天暂无会议」 │
└────┴──────────────────────┴───────────────────────────┘
```

窄窗口时快捷操作横排，议程置于下方。加载、无会议、网络失败分别呈现，不用空态掩盖请求失败。会议中导航切换不会结束媒体，会话页保留「返回会议」状态。

### 3.2 加入与会前预览

加入弹窗支持会议号、应用会议链接；粘贴链接后只解析白名单格式，再向服务端获取可见详情。权限不足时不泄露标题和名单。默认头像占位、摄像头关闭、麦克风关闭；开启预览才申请对应权限。已选择「不使用音频」则既不发送也不播放音频，与仅静音麦克风明确区分。

```text
┌ 项目评审 · 会议号 xxx xxx xxx ─────────────────────────┐
│                  摄像头预览 / 头像                     │
│                                                       │
│ [麦克风 ▾] [摄像头 ▾] [扬声器 ▾]      [加入会议]        │
│ 输入音量条 · 设备检测 · 权限提示                        │
└───────────────────────────────────────────────────────┘
```

先完成身份及资格校验，再请求入会凭证。设备不存在、被占用、系统拒绝权限时可选择仅收听或无音频入会。取消预览立刻释放采集。保存设备偏好，不保存一次性授权或自动沿用上次开摄像头行为。

### 3.3 会中线框

```text
┌ 会议详情  已进行 00:12  网络状态         布局  设置 ────┐
│                                      │成员(8) / 聊天  │
│         视频宫格 / 演讲者 / 共享内容    │搜索   [邀请]   │
│                                      │主持人 A        │
│         头像、姓名、静音与举手标记      │B  麦克风关闭   │
├──────────────────────────────────────┴───────────────┤
│ 麦克风▾ 摄像头▾ 共享屏幕 邀请 成员 聊天 举手   离开会议 │
└──────────────────────────────────────────────────────┘
```

工具栏保持可发现；每个图标有文案、焦点态和可访问名称。静音／开启状态不单独依赖颜色。侧栏默认关闭，成员和聊天互斥切换，不压缩主画面到不可用。宫格按可见页订阅视频，离屏不持续高清拉流；发言人高亮设置稳定时间，避免音量波动频繁切换。

共享后以共享流为主画面，摄像头仍可保留。首期同一时间只允许一人共享，其他人可请求主持人处理；不自动抢占。选择源后明确点击「开始共享」，持续显示共享边框／状态和停止按钮；源窗口关闭、系统停止采集、权限撤销都结束共享并恢复原布局。

## 4. 核心流程

### 4.1 组织群发起与主动加入

1. 群顶部增加「发起会议」，菜单可选择立即开始或预约。默认标题「群名的会议」。
2. 即时会议先进入预览；用户确认后创建、准备会议并入会。成功开始后发布群卡片及顶部进行中横幅。
3. 未被单独邀请的现有群成员也可点击「加入」，服务端以当前群成员资格校验；不要求发起人逐个邀请。
4. 群成员可稍后加入，不受呼叫超时影响。默认不全群响铃，卡片按普通消息规则显示。
5. 一个群允许多场会议并行；顶部显示最近一场及「还有 N 场」，展开选择，不能把群 ID 直接用作唯一 RTC 房间号。
6. 新成员可加入仍进行中的群会议；退群／被移出成员取消基于群的资格，在会者由服务端执行移除。若存在独立显式邀请，则按独立资格重新判断。
7. 会议结束，横幅移除；历史卡片显示「已结束」及实际时长，仍可打开有权限的详情。

### 4.2 单聊发起与邀请其他人

单聊顶栏提供「发起会议」及预约选项。A 创建后，B 收到邀请卡片与短时呼叫提示，接受后进入预览，再确认入会。A 不必等待 B 接受即可在房间等待。此处呼叫由 Meeting 自身通过 JuggleIM 自定义消息实现，不使用 JuggleCall；呼叫接受只触发入会流程，不创建另一场音视频通话。

会中 A 或有邀请权限的 B 可邀请 C、D；沿用组织成员选择器，排除机器人、跨组织身份和已在会成员。C、D 通过各自个人邀请加入同一 `meetingId`。**原 A-B 私聊及其历史不对 C、D 开放**，会内聊天使用独立的 JuggleIM 聊天室。

「拒绝本次呼叫」只结束响铃，不等于拒绝日历邀约、不撤销后续入会资格；「婉拒预约」是单独的 RSVP 操作。被主持人撤销邀请则失去该邀请提供的资格。建议呼叫 30 秒超时、重复呼叫 60 秒冷却，服务端限频；超时卡片仍可用于入会。

### 4.3 预约与日历

预约字段：标题（必填）、开始与结束时间、时区、描述、参会人、关联组织群（可选）、提醒、入会静音、允许成员邀请。默认 30 分钟、提前 10 分钟提醒；结束必须晚于开始。创建者为组织者，群预约自动具备群成员可加入规则。

- 「我的会议」包含我组织、显式受邀、主动添加或实际参加的会议。群内可参加会议单独筛选，避免所有群会议占满个人日历。
- 日／周视图按时间轴展示，月视图按日汇总并可展开。跨天事件分段展示，重叠并排；按当前显示时区排布。
- 冲突只提示，不阻止预约，不公开他人私有事件详情。首期冲突仅基于本系统已有授权日程，不假装覆盖外部日历。
- 受邀状态为待响应／接受／待定／拒绝；与是否在会、是否曾参加独立记录。
- 组织者编辑主题、时间、名单后增加版本并通知受影响用户；改期撤销旧提醒，拒绝状态保持，UI 提示日程已更新，可重新响应。
- 取消会议保留取消记录、撤销提醒及入会资格，卡片同步标记。已开始的会议使用「结束」，不能取消抹掉历史。
- 预约时间不等于房间存活时间：提前入会时等待主持人；主持人开始后进入进行中。计划结束时提醒，不强制断会。超过计划结束 30 分钟仍未开始则标记未举行，重新开会需创建新实例。
- 时间保存 UTC 时刻和 IANA 时区，显示明确时区；夏令时不存在或重复时刻要求用户选择有效时间。
- 提醒由服务端持久任务生成，通过 IM 下发；Desktop 在线时可显示系统通知。退出应用时不承诺原生通知必达，重新登录只展示未过期提醒摘要，不补响所有旧铃。
- 外部日历、ICS 导出及周期会议为后续扩展。周期会议须增加系列和单次实例 ID，单次取消与整个系列变更分开设计。

### 4.4 离开、结束与异常退出

普通成员只有「离开会议」。主持人看到「离开并转交」和危险按钮「结束所有人的会议」，全员结束前确认。仅一人时可直接结束；正常离开时不允许留下无主持的活跃房间。

关闭窗口触发离会确认，最小化继续通话。主窗口关闭到托盘时会议保持；退出整个应用提示正在会议中。会中切换组织或退出账号先离会并清理上下文。崩溃／断网时显示重连，保留原静音和摄像头选择，不自动重新开启设备。

## 5. 权限表

| 操作 | 组织者 | 当前主持人 | 普通参会者 |
| --- | --- | --- | --- |
| 编辑／取消未开始预约 | 是 | 仅兼任组织者时 | 否 |
| 加入符合资格的会议 | 是 | 是 | 是 |
| 邀请同组织成员 | 是 | 是 | 默认是，可关闭 |
| 共享、会内聊天、举手 | 在会且策略允许 | 在会 | 在会且策略允许 |
| 请求他人解除静音 | 在会且为主持人 | 是 | 否 |
| 全员静音、移除成员、锁定会议 | 在会且为主持人 | 是 | 否 |
| 转交主持、结束全员会议 | 在会且为主持人 | 是 | 否 |

不允许远程强制打开他人摄像头／麦克风。全员静音下发关闭策略，解除静音是请求，用户主动同意。主持人不是组织管理员权限的替代；所有修改由服务端鉴权。

锁定阻止新入会，已在会短暂断线在有效会话租约内可恢复；被移除者不可利用重连绕过。等待室、联席主持、强制发言权限放在后续版本。
