# 会议 UI 精细化

本轮沿用应用的黑白主题和圆角描边图标，调整首页、预约与预览弹窗、会中面板和小浮窗。

- 首页：统一卡片间距和文字层次，入口悬浮上移 3px，配合轻阴影；安排列表卡片化；日期选中反馈；空状态增加预约入口。
- 表单：输入框悬浮边框、成员选择背景反馈、弹窗 200ms 入场和独立操作区。
- 会中：深色渐变视频底板、成员头像与身份、聊天空状态、共享/成员/聊天按钮选中态，以及更紧凑的工具栏。
- 小浮窗：保持 260×82、顶部 30px、控制区 52px，不增加内边线；按钮提供悬浮和按压反馈。
- 动效：仅作用于按钮、弹窗、侧面板；原生大小窗口不加显隐动画，不改媒体生命周期。遵循 prefers-reduced-motion。
- 无修改服务端、ZEGO 配置与授权逻辑。

验证：前端 typecheck、原生双窗口控制器 3 项测试、git diff --check 通过。Electron 实际核对首页和预约弹窗；点击 11 月 10 日后左侧显示对应空安排，仍保留首页小日历，无横向溢出。没有提交预约，也未进行新的真实音视频联调。

## 交互细化补充

- 会议消息采用同一行组合输入栏，左侧输入，右侧固定发送按钮。
- 会中工具按钮固定宽高，静音、视频和共享文案变化不改变按钮尺寸；每次新入会默认收起侧栏。
- 邀请参会参照聊天建群界面，使用搜索、字母分组、头像勾选、已选成员双栏、移除和人数反馈；无选择时不可发送。
- 首页仅首次加载或切换月份/账号/组织时显示加载态；30 秒轮询、焦点恢复和会议变更在后台更新现有列表，不再用加载提示替换列表，也不在请求开始时移除错误区域。
- 验证：typecheck 和双窗口 3 项回归通过；当前 Electron 窗口只读确认默认无成员面板、六个工具按钮均宽 76px；聊天栏实测输入框与 48px 发送按钮同行。没有操作设备或结束当前会议。

## 按钮与轮询实测

单人临时会议实际切换麦克风与摄像头，发现并修复两个细节：设备操作共用 busy 会导致离开按钮变灰；工具栏通用 active 样式存在 1px 按压位移。离开入口不再跟随设备 busy 禁用，确认弹窗仍保留 busy 保护；工具栏取消按压位移。

修复后重复开关麦克风、摄像头，16ms 采样中所有按钮几何状态只有一种，离开按钮固定 96×38、opacity=1、disabled=false。首页采样超过 41 秒（833 帧），覆盖 30 秒轮询，安排区域 top=353、height=441、4 行保持不变，未出现加载态。类型检查通过。

共享入口已触发，但 macOS screen 权限 denied，本轮未验证成功共享/停止共享流程。测试会议已结束。

## 失焦行为调整

按最新交互要求，视频会议窗口失焦时保持显示，不自动隐藏或切换小浮窗。点击其他窗口、桌面空白区域，以及主窗口自身的隐藏/最小化，都不会隐藏仍可见的会议窗口。会议窗口本身最小化或隐藏时仍显示小浮窗；初始化就绪检查也不再以是否聚焦作为切换条件。相关 3 项原生窗口回归测试通过。该调整在 Electron 主进程，需重启应用生效。

## 音频独立切换、遮挡浮窗与重复加入

- 麦克风切换不再停止推流或销毁本地视频：已有音轨使用静音控制，首次开启仅采集音频并通过当前 SDK 的 addTrack 接入原流，保留视频轨道和画面。音频失败不重置摄像头状态。
- 当前集成使用 createStream 的 MediaStream 兼容接口；参考 [ZEGO API](https://www.zegocloud.com/docs/live-streaming-web/client-sdk/api-reference/class) 中 addTrack/replaceTrack。后续整体升级 createZegoStream 时一起迁移，不混用两种本地流类型。
- 失焦时展示小浮窗但不隐藏视频窗口；重新聚焦时收起小浮窗。采用失焦作为被其他窗口遮挡的保守判断，因此点击桌面空白也会显示小浮窗，大窗仍保留。最小化、显式隐藏仍按原行为处理。
- 今日安排点击当前正在参加的会议直接聚焦现有窗口，跳过详情请求、入会预览和重复加入。其他预览入口也增加同一会议判断。
- 8 项会议运行时测试和 3 项窗口控制器测试通过，前端 typecheck 通过。未打断当前进行中的会议，也未重启 Electron；原生窗口逻辑需下次重启生效。

## 跨端声音与邀请卡片修复

- 消息模块的 MESSAGE_NAMES 白名单补齐 jw:meeting-card / jw:meeting-invite，防止已实现的卡片组件被“不支持消息”系统分支截断；会话列表预览同步支持会议标题。
- 远端音频由主渲染器中的独立 audio 元素播放，按远端流唯一挂载，视频元素全部静音避免重复声音。本地采集与本机共享流不创建音频播放元素。
- 音频轨道后到达时重试播放；播放失败提供可操作提示；离会卸载监听和播放源。可信 Electron 主窗口及会议窗口设置 no-user-gesture-required 自动播放策略，需重启生效。
- 新增自动化测试覆盖晚到音轨、播放受阻/重试、清理，以及卡片白名单和预览。11 项会议运行时测试、前端与 Electron 类型检查通过。
- 本轮未进行两端真实互听；当前运行页面无远端音频元素可供验证，不能将播放器修复等同于远端发送、网络和扬声器全链路验收。

## 2026-11-10：定位并修复 SDK 静音占位音轨

真实 ZEGO 3.12.0 联调确认：createStream({camera:{audio:false,video:true}}) 依然返回 live 的 MediaStreamAudioDestinationNode 占位音轨。旧逻辑仅检查 getAudioTracks()，误把占位流当真实麦克风，开麦只启用静音数据。SDK 对该占位流要求 addTrack；replaceTrack 返回错误，不能按普通音轨处理。

修复：显式维护 microphoneCaptured，首次开麦采集真实麦克风并用 addTrack 接入（即使已有占位音轨）；仅真实麦克风轨道失效后才使用 replaceTrack。新建捕获、销毁或切换摄像头时同步维护该标记。

云端回环验证（单账号真实 ZEGO 推流/拉流，受控测试音替代麦克风，不是两个人互听）：
- 只开视频入会：确认占位音轨存在。
- 开麦后接收峰值 0.100708；静音后 0；解除静音后 0.100711。
- 麦克风采集次数始终为 1；本地流和视频轨道对象始终不变。
- 新增 SDK 占位音轨回归测试；12 项会议运行时测试通过。
